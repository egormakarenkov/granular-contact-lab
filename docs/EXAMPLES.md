# Synthetic examples

Every supplied numerical example is generated by `scripts/generate_examples.py`. No imported recording or experimental dataset is used. Full run settings, initial arrays and dependency versions are stored with each compressed JSON recording.

1. **Floor support** (`examples/floor-support.json`): one grain at rest. Its expected support reaction is `(0.1/0.12)^2` for unit prescribed body-force parameter. This provides an analytic force-balance check.
2. **Redundant support** (`examples/redundant-support.json`): an intentionally duplicated normal constraint. The algebra is lambda_1 + lambda_2 = 1 with nonnegative lambdas. One reaction can span approximately [0,1]. This is an algebraic example, not a physical bed containing two floors.
3. **Synthetic packed bed**: 36 bidisperse discs prepared by the seeded packing routine with seed 2027. The default recording uses rigid lateral sway and downward translation for duration .6, timestep .015, amplitude .02, frequency 1 and stroke .03. The offline demo replays this case.
4. **Controlled comparison**: translation and sway begin from exactly the same arrays for each of seeds 2027, 2028 and 2029. The first pair is repeated at half timestep. All results are included regardless of which motion has lower positive work. See `examples/manifest.json` for IDs and numerical metrics. This sample is too small to establish generalization.

The full UI's Saved experiments list contains all eight recordings. Select the motion, seed and timestep from the recorded settings to identify each one. Use Compare two controls to compute a new pair, or open one run and use Fork frame for identical-state continuations.

The complete JSON fixtures preserve full numeric precision. The self-contained demo rounds numbers to nine decimal places to reduce size and should not be used as a precision reproduction input. Regeneration under different library versions can change packing or floating-point results; shipped initial arrays provide a more direct reproduction boundary.
